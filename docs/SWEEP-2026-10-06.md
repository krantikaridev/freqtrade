Madan's call: one strategy a week is too slow for a $250 sleeve, so run the cheap
experiments in parallel. This is the first parallel sweep: the live champ plus three
stock freqtrade strategy patterns, each on 1h and 4h.

Everything below is real freqtrade output from this run. Raw exports (one zip per arm,
`SWEEP.csv`, per-arm logs) are on disk under `sweep/2026-10-06/` and gitignored —
the table is the human copy, `SWEEP.csv` the machine copy.

## What the sweep says

1. **1h beats 4h for every strategy**, including the champ (+6.41% vs +4.02%). The
   scoreboard's "next iterate: 1h smoke" note is confirmed.
2. **No arm beat doing nothing.** Buy-and-hold over the same window was **+24.75%
   (4h) / +25.65% (1h)** per freqtrade's `market_change`. Every strategy is a
   fraction of that with a fraction of the risk. On a $250 sleeve the honest framing
   is: this is a discipline exercise, not a money-making one, until edge is proven.
3. **Trend is the only pattern that pays here.** EmaCross (stock pattern) landed
   second-best on both timeframes and did not need our hand-tuned ROI ladder.
   Breakout worked on 1h and lost on 4h. Mean-reversion never traded: on 4h BTC/ETH/BNB
   over this window it produced 0 trades, on 1h 6 trades — both flagged as overfit risk,
   which means "no evidence", not "small edge".
4. **Hyperopt found nothing.** Short budget (20 epochs, buy space only: EMA fast 14–28,
   EMA slow 40–80, ADX 15–30, `SharpeHyperOptLoss`) on the top arm. Best was
   `ema_fast=16, ema_slow=72, adx=22`, objective Sharpe 1.2496 — the same trade count and
   profit as the existing champ defaults. Written back as defaults and re-run, it was
   slightly *worse* at 1h (6.22% / Sharpe 1.21 vs 6.41% / 1.25). Conclusion: the champ's
   parameters are already at a local optimum; more tuning time would buy overfit risk,
   not return.

## Reproduce

```bash
cd ~/Code/krantikaridev/freqtrade
bash scripts/sweep.sh                      # downloads data, runs all arms
SKIP_DOWNLOAD=1 bash scripts/sweep.sh      # data already on disk
python3 scripts/summarize_sweep.py sweep/2026-10-06
```

Hyperopt arm:

```bash
docker run --rm -v "$PWD:/freqtrade/user_data" freqtradeorg/freqtrade:stable hyperopt \
  --config /freqtrade/user_data/config/config.sweep.json \
  --strategy TrendFollowingMaxDDHyp --timeframe 1h \
  --timerange 20260409-20261006 --fee 0.0005 --enable-protections \
  --hyperopt-loss SharpeHyperOptLoss --spaces buy --epochs 20
```

## Caveats

- Single 180-day window, one market regime, 3 large-cap pairs. Not out-of-sample;
  the champ's entry logic was already tuned on windows overlapping this one.
- 1h arms get ~4x the candles, so they also get ~4x the overfit surface. The 1h win is
  consistent across all four strategies, which is the only reason it is believed at all.
- Fewer than 30 trades ⇒ no read (rows marked above).
